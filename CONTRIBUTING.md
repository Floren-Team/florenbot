# Как внести свой вклад

Мы рады любой помощи! Пожалуйста, следуйте этим простым правилам:

## Сообщение об ошибках
Если вы нашли баг, создайте [Issue] https://github.com/Floren-Team/florenbot/issues, указав:
- Версию вашего бота.
- Шаги для воспроизведения.
- Ожидаемый и фактический результат.

## Предложения по разработке
1. Сделайте форк репозитория.
2. Создайте ветку для вашей фичи (`git checkout -b feature/cool-new-thing`).
3. Напишите код (соблюдайте стиль, принятый в проекте).
4. Запустите тесты (`go test ./...`).
5. Отправьте Pull Request.

## Правила кода
- Весь новый код должен быть отформатирован через `go fmt`.
- Добавляйте комментарии к сложным участкам логики.
