## Reporting a Vulnerability

If you discover a security vulnerability within Florenbot, please report it responsibly. 

- **Do not** disclose security-related issues publicly until they have been addressed and patched.
- Instead, please report vulnerabilities by opening a private security advisory or contacting the maintainer directly through GitHub.

We appreciate your help in keeping Florenbot and its community safe!
